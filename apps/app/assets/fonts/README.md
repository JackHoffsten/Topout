# Cascadia Mono

`CascadiaMono-Regular.ttf` is the unmodified static regular font from Microsoft's
[Cascadia Code 2407.24 release](https://github.com/microsoft/cascadia-code/releases/tag/v2407.24),
archive entry `ttf/static/CascadiaMono-Regular.ttf`.

SHA-256: `06520d032ec274fa5040b22c6f4a1d829081b24ba40b2da56dae89bf10c7b481`.

The SIL Open Font License and copyright notice are included in `LICENSE.txt`.
The font retains its original license independently of the application code.
The font file itself also includes the licensing metadata.

Expo loads this bundled asset at startup as `CascadiaMono`. Native apps use it directly.
Web uses it as the fallback after Consolas, without an external font/CDN request.
