# Persist workout-local exercise replacements on the affected entry

Exercise replacement must preserve identity, workout position and set structure even before results are recorded, while relabelling existing results atomically. Store the original exercise ID, workout position and normal or left/right set structure on only the replaced log entry, including entries with no results; recording or removing results updates that structure, and retired identities remain excluded to reject stale requests. This extends [ADR 0001](0001-workout-exercise-removal.md) without snapshotting untouched template exercises: replacement survives reopening, while general unlogged additions and other draft edits retain their existing restoration rules rather than introducing general draft autosave.
