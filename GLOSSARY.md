# Topout

Topout tracks workouts and climbing activity.

## Language

**Last logged**:
The previous recorded result for an exercise at a particular set position and
side, preferring the workout's location when matching history exists.

**Workout**:
A training session consisting of exercises and sets, which can be planned and
logged.
_Avoid_: Gym as a name for this activity.

**Exercise replacement**:
Substitution of one exercise with another from the exercise library within a
single workout, including any sets already logged for that exercise and leaving
its workout template unchanged. Recorded set values are preserved.
